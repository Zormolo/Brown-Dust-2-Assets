# Contributing

Contributions to this project are welcome!

You are welcome to submit:
- Bug fixes
- Improvements
- New features
- Documentation
- Code optimizations

## Contribution Rules

1. Contributions must be submitted through pull requests.
2. Contributions must be your own original work or work you have permission to submit.
3. Do not submit copyrighted material without the necessary permissions.
4. Do not submit assets belonging to third parties without confirming that their use is permitted.
5. All contributions must comply with the project's LICENSE and contributor agreement.

## Important

Contributing to this repository does not grant you permission to reuse the project's original source code in other projects.

Contributions may only be incorporated into this project under the agreed contribution terms.

The project maintainer reserves the right to accept or reject any contribution.
